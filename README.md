# DIA-lab4
Лабораторная 4 по курсу Разработка интернет-приложений (МГТУ Канев А.И.)

ПОСТАНОВКА ЗАДАЧИ

Реализовать методы бэкенда для аутентификации и регистрации. Авторизация через хранение сессий и куки для NestJS, а для Golang соответственно JWT и blacklist. Автозаполнение пользователя в таблице заявок при создании новой. Добавить описание методов для swagger.

Добавить проверку Permissions для методов модератора. Без авторизации в Swagger должно быть доступно только чтение-получение данных через API, с авторизацией - методы пользователя, а для модератора доступны все методы.
